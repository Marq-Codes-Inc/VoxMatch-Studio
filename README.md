# VoxMatch Studio

**VoxMatch Studio** is a desktop application designed to streamline audio transcription workflows. Built with Electron and setup with react-vite, it offers an intuitive interface for managing, transcribing, and editing audio files. Key features include:

- **Audio Import:** Easily add and organize audio files for transcription.
- **Transcription Tools:** Integrated editor for manual and assisted transcription.
- **Playback Controls:** Fine-tuned playback options for efficient review.
- **Export Options:** Save transcriptions in multiple formats for further use.

VoxMatch Studio is ideal for creators, ideo editors, journalists, researchers, and anyone needing accurate, efficient audio transcription on their desktop.
